Countdown Project

This is a .NET MAUI app of the classic countdown gameshow.
Two players fight to guess the longest word within 30 seconds (Timer customisable)

Features:
Customiseable timer
Guessed word is validated via a external dictionary
Automatic scoring
Win / Loss history
Light / Dark mode #

How to run:
Clone the repo or download the project
Open the sln file
Clean and rebuild
Run on Windows / Android
